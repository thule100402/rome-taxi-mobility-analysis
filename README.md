# Rome Taxi Mobility & Geospatial Analysis
# Business Problem
Urban transportation systems generate large volumes of GPS data that can be analysed to identify mobility patterns, transportation demand, and operational inefficiencies.

This project analyses taxi GPS records from Rome, Italy to evaluate driver activity, geographic movement behaviour, and urban mobility trends.

# Objective
Detect invalid GPS records and outliers
Analyse taxi movement behaviour
Evaluate driver activity levels
Generate operational and geographic insights

# Dataset
Large-scale taxi GPS dataset
1.2GB of spatial-temporal data
21.8 million rows of data
Includes timestamps, latitude, longitude, and driver IDs

# Tools & Techniques
R
DBSCAN clustering
ggplot2
Geospatial analysis
Statistical analysis

# Key Insights
Taxi activity concentrated heavily in central urban areas
Driver activity levels varied significantly
GPS datasets contained substantial spatial noise
Individual driver behaviour differed from overall fleet patterns

# Business Recommendations
Improve taxi fleet allocation in high-demand zones
Enhance GPS anomaly detection systems
Support transport planning through mobility analytics
