# rome-taxi-mobility-analysis
Geospatial and mobility analysis of large-scale taxi GPS data using R, DBSCAN, and statistical analysis.

# Rome Taxi Mobility & Geospatial Analysis
# Business Problem
Urban transportation systems generate large volumes of GPS data that can be analysed to identify mobility patterns, transportation demand, and operational inefficiencies.

This project analyses taxi GPS records from Rome, Italy to evaluate driver activity, geographic movement behaviour, and urban mobility trends.
